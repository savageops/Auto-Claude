# Add skeleton loading states for KanbanBoard and WelcomeScreen

## Overview

Implement skeleton loading components for the main content areas (KanbanBoard columns, WelcomeScreen recent projects list) to provide visual feedback during data loading, similar to the existing IdeaSkeletonCard pattern.

## Rationale

Currently, when tasks or projects are loading, users see either blank content or a flash of empty state. Skeleton screens reduce perceived loading time and prevent layout shifts, creating a smoother experience.
